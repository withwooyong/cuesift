> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `cuesift translate`에 Tier 1 옵션 4종을 붙이고, Tier 1이 쓴 토큰을
`review.json`까지 올려 FR-4.3과 FR-7.4를 함께 닫는다.

**Architecture:** Tier 1은 **opt-in**이다(D2). `--tier1`이 없으면 기존 경로가 그대로

`CountingProvider`로 감싸 **실제 나간 호출의 토큰만** 센다(D7). 신호 계층
(`signals/`)은 **0줄** 바뀐다(D13).

pytest · pytest-cov · ruff (dev 3개 고정)

- [ ] **Step 3: `__post_init__`을 구현한다**

`CacheRequest`의 `attempt` 필드 선언 아래, `messages_sha` 프로퍼티 **위**에 넣는다.

```python
    def __post_init__(self) -> None:
        """`attempt`의 도메인을 생성 시점에 고정한다 (FR-4.1 · 설계 D11).

        **`None`이 들어오면 무음 열화가 된다.** 아래 `key`가 falsy를 만나
        `attempt` 조각을 붙이지 않으므로 `key(None) == key(0)`이다. 그러면
        자가일관성의 N회 호출이 한 캐시 항목으로 뭉쳐 샘플이 1개가 되고,
        `SelfConsistency`의 `len(samples) < 2 -> None` 가드는 **우회된다** -
        그 가드가 보는 것은 "샘플이 몇 개인가"이지 "몇 번 불렀나"가 아니다.
        결과는 "판정 불가"가 아니라 **점수 0.0**, 곧 "안전"이다.

        | 값 | 호출 수 | score | 무엇으로 보이나 |
        | --- | --- | --- | --- |
        | `attempt=i` (정상) | 3회 | 0.0286 | 판정됨 |
        | `attempt=None` | 1회 | 0.0000 | **"판정했고 안전"** |

        bool은 int의 서브클래스라 `attempt=True`가 이 검사를 통과하지만,
        `key`에서 `attempt=1`과 **같은 문자열**을 만들므로 뭉침이 일어나지
        않는다 - 별도로 막지 않는다(`Tier1Context.samples`가 bool을 `< 2`로
        걸러 내는 것과 같은 판단이다).
        """
        if not isinstance(self.attempt, int):
            raise ValueError(f"attempt는 int여야 한다 (받은 타입: {type(self.attempt).__name__})")
        # 음수는 `attempt=-1`로 키에 그대로 실려 **유효한 키를 만든다** -
        # 뭉치지는 않지만 시도 번호의 도메인 밖이라 호출부가 `range()`를 잘못
        # 조립했다는 신호다. 통과시키면 그 실수가 캐시 파일로 굳는다.
        if self.attempt < 0:
            raise ValueError(f"attempt는 0 이상이어야 한다 (받은 값: {self.attempt})")
```

`frozen=True, slots=True`에서 `__post_init__`은 정상 동작한다 - 값을 **검사만** 하고
바꾸지 않기 때문이다.

```python
@dataclass
class CountingProvider:
    """통과한 `Completion`의 토큰을 누적하는 위임 래퍼 (FR-7.4 · 설계 D6·D7).

    **`collect_tier1`의 반환형을 바꾸지 않고 Tier 1 비용을 얻는 수단이다.**

    아래로 내려간다 - 그 성질을 이용한다(설계 §3.3).

    **`CachingProvider`의 안쪽에 놓인다**(D7). 캐시 히트는 `complete`를
    부르지 않으므로 여기 잡히지 않고, 그것이 정확한 동작이다 - 실제로 쓰지
    않은 토큰이다. 바깥에 두면 *요청한* 호출을 세게 되어 `cost`가 청구서와
    어긋난다.

    **예외를 잡지 않는다.** `Provider.complete`의 계약 셋(오류는
    `Retryable`/`Fatal`로 던진다 · `text`는 반드시 `str` · 재시도하지
    않는다)을 위임으로 그대로 통과시킨다. 여기서 `except`를 달면
    `SelfConsistency`가 `FatalProviderError`를 일부러 다시 던지는 설계
    (`signals/llm.py`)가 무력해져, 401이 난 실행이 **"Tier 1이 돌았고
    아무것도 안 걸렸다"** 로 보인다.
    """

    inner: Provider
    usage: TokenUsage = field(default_factory=TokenUsage)

    @property
    def name(self) -> str:
        # 래퍼 이름이 새면 `identity` 조립이 달라져 **캐시가 통째로 갈라진다** -
        # 이전 실행의 캐시를 한 건도 못 읽는다.
        return self.inner.name

    def complete(
        self,
        messages: Sequence[ChatMessage],
        *,
        temperature: float,
        max_tokens: int | None,
    ) -> Completion:
        completion = self.inner.complete(
            messages, temperature=temperature, max_tokens=max_tokens
        )
        self.usage = self.usage + completion.usage
        return completion
```

`_run_triage`의 `_outcome()` 안에 이미 이렇게 있다(`cli.py`에서 `resolve_cost_scope`로 찾아라 - 줄 번호는 낡는다):

```python

        return TriageOutcome(
            ...,
            usage=scope.usage,
            cost_includes=scope.includes,
            cost_unreported=scope.unreported,

```

Tier 1을 켜면 **매핑에 한 줄을 더한다. 그것이 전부다:**

```python

            {
                "translation": translated.usage,
                "tier1": None if tier1 is None else tier1.counting.usage,
            }
        )
```

`usage=`·`cost_includes=`·`cost_unreported=` 세 줄은 **손대지 않는다.**

**왜 손으로 합치면 안 되는가.** `usage`를 `+`로 합치는 순간 계층별 정보가 **복원 불가**가
된다. 실측 - 합쳐서 키 하나로 넘기면 `{"translation": tr + t1}` → `includes=("translation",)`·
`unreported=()`로 **Tier 1이 통째로 지워지고 판정도 통과한다.** 그러면
`TokenUsage(prompt=1, completion=0, calls=1000)`에서 **1토큰이 999회 무음 호출을 가려**
`tokens_reported: true`가 나간다(요구사항정의서 §12 Q3가 경고한 "번역=상용 API /
Tier 1=로컬 Ollama" 구성이 정확히 여기 걸린다). 그래서 합계도 `resolve_cost_scope`가 낸다 -
호출자가 손으로 합칠 이유를 없애는 것이 이 형태의 목적이다.

**`None`과 `TokenUsage(0, 0, calls=N)`은 다르다.** 전자는 "그 계층이 안 돌았다"(범위·합계에서
제외), 후자는 "돌았는데 무음"(`unreported`에 실린다). Tier 1이 꺼져 있으면 `None`이다.

`resolve_cost_scope`·`CostScope`는 `cuesift.report`에서 가져온다.
